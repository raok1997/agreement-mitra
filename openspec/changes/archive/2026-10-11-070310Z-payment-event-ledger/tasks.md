## 1. Schema and ledger types

- [x] 1.1 Add `backend/src/main/resources/db/migration/V29__payment_event.sql`: table `payment_event` with the columns and widths of design D6 (identity `id`, `attempt_key CHAR(64)`, `first_received_at`, `last_received_at`, `attempt_count`), a unique index `uq_payment_event_attempt_key` on `attempt_key`, and `idx_payment_event_order_first_received` on `(provider_order_id, first_received_at)`. No foreign key (D7) and **no check constraint on `source` or `outcome`** (D6). Header comment: a row is one distinct attempt and a count of its repeats; it is written outside the confirmation transaction; it holds no payer PII and no payload; `presented_event_id` is not authenticated
- [x] 1.2 Add `PaymentEventOutcome` (package-private enum, `signing.payment`): the six `ConfirmationOutcome` names plus `RECORDING_FAILED` and `ERRORED`, with `of(ConfirmationOutcome)` (D8)

- [x] 1.4 Add `PaymentEvent` (package-private record, not a JPA entity) with a static factory that makes every string storable - removes NUL and U+001F, truncates to the column width, drops a trailing unpaired high surrogate - and computes `attemptKey` from the values it is about to store: the lower-case SHA-256 hex of the nine key values joined by U+001F, UTF-8, the amount as `Long.toString`, enums by `name()`, and a single NUL character standing for `null` (D6, D9). The presented event id and the received time are not part of the key
- [x] 1.5 Add `PaymentEventLedger` (package-private `@Component`): `record(origin, providerOrderId, providerPaymentId, amountMinorUnits, currency, receivedAt, outcome, refusedRule, sqlState)` running the one `INSERT ... - [x] 1.6 Unit test `PaymentEventOutcomeTest`: every `ConfirmationOutcome` value maps to the outcome of the same name; every `PaymentEventOutcome` and `Source` name fits its column width
- [x] 1.7 Unit test `PaymentEventOriginTest`: a plain event id is kept; a 65-character one, one holding a space, a slash or a newline, a blank one and `null` are all stored as absent; the callback and reconciliation origins carry no event id and no event type
