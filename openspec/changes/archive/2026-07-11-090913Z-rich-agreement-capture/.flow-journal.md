# Flow journal -- rich-agreement-capture (CR-1)

The first CR of the guided rental-agreement arc. Captured, reviewed, implemented, and
manually verified end-to-end against the live stack, then archived.

## Decisions taken (with the user)

- **Anonymous-first**: drafting needs no login; the mobile-OTP save/resume layer
  (`mobile-otp-auth`) is a separate, parked nice-to-have. This CR stays on the anonymous
  create path and changes no security matcher.
- **Additive, non-destructive migration (`V7`)**: keep `signer.name` and
  `agreement.term_months`; add structured party fields plus tenancy dates. `name` becomes the
  full name as per Aadhaar -- auto-derived from first+last, user-editable to match the
  Aadhaar record, and used as the eSign invitee name. `term_months` becomes server-derived
  from the dates.
- **Money names unchanged**: `monthlyRent` / `securityDeposit` kept; the UI labels them
  "Monthly Rent" / "Security Deposit".
- **Duration in months**: derived from start/end dates (whole months, exclusive of the end
  date); no years/months/days breakdown.
- **Contact optional at draft, either channel suffices**: capture both email and mobile;
  at least one is required only before a signing request (a `409 CONTACT_REQUIRED`); the
  eSign invite is addressed to both channels when present.

## Implementation

- Backend: `V7__rich_agreement_capture.sql`; `Signer`/`Agreement` fields; `TenancyDuration`;
  name plus term derivation in `AgreementService`; reshaped `CreateAgreementRequest` and
  `AgreementResponse`; `@EndAfterStart` plus adapted `@ValidSignerSet`; pre-signing
  contact-required `409` plus both-channel invitee.
- Frontend: `CaptureForm.vue` (Tenant/Owner/Property sections, live duration, auto-derived
  name with Aadhaar override); `createAgreement` plus `durationMonths` in `src/api/client.ts`.

## Post-review UX changes (public, all-India app)

- Field-level friendly validation messages (backend) instead of one combined
  `@ValidSignerSet` message; for example "Each person needs a different email address."
- Client-side checks (duplicate email, end-after-start) with plain messages before submit;
  `required` on all fields except email/mobile; errors rendered as a readable list.
- Removed the old "Aadhaar eSign demo" stub (`SignDemo.vue` plus test); the app now shows
  only the capture form under "Create a Rental Agreement".
